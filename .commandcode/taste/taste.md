# Taste

## Communication style
- Writes in terse, lowercase, informal shorthand with minimal punctuation (e.g., "why i can use commandcode api"). Confidence: 0.7
- Asks conceptual "why/how does this work" questions about their setup and benefits from plain-language explanations of underlying mechanics, not just step-by-step instructions. Confidence: 0.5

## Workflow
- Expects the agent to verify claims against their actual local machine by running shell commands to inspect configs/setup, rather than answering from assumptions or general knowledge. Confidence: 0.6
