# ch01 — Emulator Laboratory Infrastructure

The infrastructure chapter: endianness, bit extraction, binary
inspection, and the skeleton generator itself. Everything later chapters
assume as reflexes is built (and machine-checked) here.

## Exercises

| exercise | artifact | gate component |
|---|---|---|
| `01_endian_bits` | `read_le16/be16/le32` + `bits(value,start,count)` with labstest suite | exercises |
| `02_hex_dumper` | CLI hex dumper (`hexdump -C` format) + unit tests via captured output | exercises |
| `03_generator_starter` | YOUR simplified skeleton generator (`generate_skel.py`) over three fixture templates, deterministic manifest | starter |
| `90_debug` | two seeded endian-decoder bugs + `DEBUGGING.md` + your `bug-report.md` | debugging |
| `91_challenge` | `LABS="ch01/a ch01/b ch01/c"` multi-target flow over three mini templates + hash verification | challenge |
| `99_coding_test` | unseen seven-level template; all nine valid generated variants must hash-match | coding test |

## Workflow

```bash
LABS=ch01_lab_infrastructure make skels     # generate skeletons
make build && make test                     # RED is expected at first
LABS=ch01_lab_infrastructure/01_endian_bits make skels   # one exercise only
TODO=3 LABS=ch01_lab_infrastructure/03_generator_starter make skels  # resume at level 3
make solutions                              # reference tree (study after solving)
```

## Gate checklist

Per curriculum §4 the chapter unlocks ch02 when ALL of:

- [x] **exercises** — `ctest` suites for 01/02 go GREEN in your skeleton
      tree (skeleton ships RED by design),
- [x] **starter** — your `generate_skel.py` passes every fixture/level
      golden (`ctest -R ch01_03_generator`),
- [x] **debugging** — `ch01_90_debug` suite GREEN + `bug-report.md`
      written per `DEBUGGING.md`,
- [x] **challenge** — acceptance list in `91_challenge/CHALLENGE.md`
      ticked, checker `challenge` mode passes,
- [x] **coding test** — hidden manifest fully passing:
      `make grade GRADE_TARGETS=ch01_lab_infrastructure`.

There is no theory quiz that can compensate for broken code.

```
tests/public/ch01_lab_infrastructure/   provenance of goldens + public fixtures

```

Note on `%`-sentinel markers: fixture templates stored under
`03_generator_starter/data/` and `99_coding_test/data/` spell their
markers `%LABS-BEGIN` so the repository generator copies them through
verbatim; generators treat `%LABS-` exactly like `@LABS-`. See
`03_generator_starter/SPEC.md`.
