# ch02_emulator_core — Building an Emulator Core

Read [LECTURE.md](LECTURE.md) for the universal fetch/decode/execute loop and
[SPEC.md](SPEC.md) for the LAB-8 fictional CPU (4 registers, 256-byte RAM,
8 instructions, Z/C flags). Every exercise implements a slice of that spec.

## Workflow

```bash
LABS=ch02_emulator_core make skels          # or one exercise:
LABS=ch02_emulator_core/03_control_flow make skels
make build && make test                     # implement TODO(n), repeat

# trace-first debugging against golden traces
./build/skels/ch02_emulator_core/04_assembler_fixture/ch02_04_runner \
    --rom tests/public/ch02_emulator_core/roms/countdown.bin \
    --cycles 400 --trace /tmp/mine.log
python3 tools/labs/compare_trace.py \
    tests/public/ch02_emulator_core/traces/countdown.log /tmp/mine.log
```

Trace format (canonical across all chapters):
`pc=<hex> op=<hex> r0..r3=<hex> cyc=<n>`, pre-execution state, per-instruction
cycle cost last. Golden traces + provenance:
`tests/public/ch02_emulator_core/traces/provenance.md`.
