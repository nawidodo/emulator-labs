# 03 — Noise channel (LFSR)

Channel 4 is a 15-bit maximal-ish LFSR clocked at a programmable rate and
scaled by the pulse-style envelope. Registers: NR41 ($FF20 length code),
NR42 ($FF21 envelope), NR43 ($FF43: s bits 4-7, width7 bit 3, divisor
code bits 0-2), NR44 ($FF23 trigger/length-enable).

## Committed model

| seq | function | contract |
|-----|----------|---------|
| 1 | `stepPeriod` | `kNoiseDivisors[code] << s` with table `{8,16,32,48,64,80,96,112}` |
| 2 | `step` | exact formulation (see below) |
| 3 | `trigger` | enable; reload length 0 -> 64; lfsr = 0x7FFF; reload envelope + step timers |
| 4 | `advance` | while enabled, one `step()` per period expiry |
| 5 | `sample` | disabled/DAC-off -> 0; else `(~lfsr & 1) * volume` |

The exact LFSR step — do not "simplify" it:

```cpp
int x = (lfsr ^ (lfsr >> 1)) & 1;
lfsr = (lfsr >> 1) | (x << 14);
if (width7) set BOTH bit 6 and bit 14 to x;
```
