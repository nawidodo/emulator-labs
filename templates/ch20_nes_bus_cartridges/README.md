# Chapter 20 — NES Bus and Cartridges

Below $4017 the NES is one machine; above it, whatever cartridge you plug
in. This chapter builds the CPU-side bus decode with all its mirroring
traps, the iNES container format, and the Mapper connector — then proves
the whole stack by booting a course-original NROM ROM headlessly.

## Exercises

| Dir | Task |
|---|---|
| `01_cpu_bus` | 2KB RAM mirrored across $0000-$1FFF, eight PPU registers mirrored across $2000-$3FFF, strobe-latched controllers at $4016/$4017, OAM DMA at $4014 with the official 513/514-cycle debit |
| `02_ines_nrom` | iNES header parser (banks, mapper low nibble, mirroring bits), `Mapper` interface, NROM with its 16KB-bank mirror and hard-wired CIRAM layout |

## Debug

`90_debug` — two seeded bugs: the header's mirroring bit read backwards
(every game scrolls on the wrong axis) and OAM DMA charging a flat 513
cycles (alignment get-cycle dropped). Students produce `bug-report.md`.

## Challenge

`91_boot` — boot `boot_success.nes` headlessly: reset through the
cartridge vector, let the ROM's own init code write the success code to
RAM `$02`, assert through the bus. Runner:
`--rom x.nes --headless --cycles N --dump-ram FILE --expect-ram ADDR=HEX`.

## Coding test

`99_coding_test` — from a supplied spec table only: the mapper-zero CHR-RAM
variant (`chr_banks == 0` means 8KB writable CHR instead of ROM).
