# Challenge — ch21: hash three crafted scenes

Produce framebuffer hashes for simple "test ROMs". In this chapter the test
programs are crafted PPU-state snapshots (NESF v1): no CPU, pure VRAM
states, exactly like a real emulator's screenshot-diff tests.

## Task

Run your Chapter 21 renderer over each fixture and reproduce these FNV-1a
64 hashes of the raw 256x240 RGBA8 frames:

| Scene | File | FNV64 |
|---|---|---|
| checker grid, 4 palettes | `fixtures/scene_grid.nesf`   | `985B8113C024BB25` |
| attribute quadrant wall  | `fixtures/scene_attr.nesf`   | `34F0650F536BE325` |
| mirrored nametables      | `fixtures/scene_mirror.nesf` | `3FF17E99E3612325` |

Command shape (adjust binary path to your build tree):

```bash
./ch21_03_render_runner --rom fixtures/scene_grid.nesf --frames 1 \
    --hash-frame /tmp/grid.rgba
python3 tools/labs/hash_frame.py /tmp/grid.rgba --fnv-only
```

## Acceptance criteria

- All three hashes match exactly.
- `--frames 3` produces the same hash as `--frames 1` (static scene,
  deterministic renderer).
- You can explain, per scene, which mirroring mode it exercises and why
  your PpuBus passes.

The goldens were generated by the reference solution (run twice,
identical); provenance under `tests/public/ch21_nes_ppu1/goldens/`.
