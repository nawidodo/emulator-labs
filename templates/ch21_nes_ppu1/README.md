# ch21_nes_ppu1 — NES PPU I: Memory & Background Rendering

First PPU chapter. The PPU gets its own address bus and its own memory
structures; you render full 256x240 background frames from crafted VRAM
states and pin them with golden hashes.

## Exercises

| Dir | Topic | Key artifacts |
|---|---|---|
| `01_ppu_bus` | PPU address space, nametable mirroring, palette mirroring | `ch21_01_ppu_bus_tests` |
| `02_bg_pipeline` | attribute quadrants, planar tile decode, backdrop rule | `ch21_02_bg_tests` |
| `03_render_frame` | NESF snapshot fixture -> RGBA frame, headless runner | `ch21_03_render_tests`, `ch21_03_render_runner` |
| `90_debug` | seeded defect: attribute quadrant shift swapped | `ch21_dbg_tests` + bug-report.md |
| `91_challenge` | reproduce golden hashes for three crafted scenes | CHALLENGE.md |
| `99_coding_test` | render an unseen nametable snapshot | CODING_TEST.md |

## Fixture format

`.nesf` (NESF v1) — a crafted PPU state: CHR, physical VRAM, palette RAM,
OAM plus register state. Layout documented in
`03_render_frame/fixture.hpp`; scenes are committed under
`tests/public/ch21_nes_ppu1/fixtures/` with a `provenance.md`.
