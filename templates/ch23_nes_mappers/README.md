# ch23_nes_mappers — NES Cartridge Mappers

Bank switching: UxROM, CNROM, MMC1's serial shift register, and MMC3 with
its scanline IRQ. Everything is tested through the mapper interface
directly — `cpu_read`/`cpu_write`/`ppu_read`/`ppu_write` harness calls, no
CPU core required.

## Exercises

| Dir | Topic | Key artifacts |
|---|---|---|
| `01_ines_header` | iNES parse + `Mapper` interface + cart runner | `ch23_01_ines_tests`, `ch23_01_ines_runner` |
| `02_uxrom_cnrom` | switchable-PRG and switchable-CHR boards | `ch23_02_uxcn_tests` |
| `03_mmc1` | 5-write shift register, PRG/CHR modes, mirroring control | `ch23_03_mmc1_tests` |
| `04_mmc3` | R0-R7 banking, inverted mirroring polarity, IRQ counter | `ch23_04_mmc3_tests` |
| `90_debug` | seeded defect: MMC3 latch copied into the counter on `$C000` writes | `ch23_dbg_tests` + bug-report.md |
| `91_challenge` | reproduce golden MMC3 interrupt logs from op scripts | CHALLENGE.md, `ch23_91_irq_runner` |
| `99_coding_test` | implement the fictional MFX-1 from a register spec | CODING_TEST.md, `ch23_99_mfx_tests`, `ch23_99_mfx_runner` |

## Fixtures

Synthetic `.nes` carts (no commercial ROMs) are generated by
`tests/public/ch23_nes_mappers/tools/gen_carts.py` and committed under
`tests/public/ch23_nes_mappers/fixtures/` with a provenance note.
Challenge/coding-test scripts are course-original text fixtures committed
inside the exercise dirs; golden interrupt logs live in
`tests/public/ch23_nes_mappers/goldens/`.
