# ch24_nes_apu_dma_sync — NES APU, DMA and Final Synchronization

The NES phase milestone: pulse/triangle/noise/DMC channels, the frame
counter with its IRQ edges, OAM DMA cycle accounting (513/514), and a
CPU:PPU catch-up scheduler whose ratio is pinned by frame+audio hashes.

## Fixtures & scripts

Op-script grammar (course-original): `pal`, `chrpat`, `nt`, `wr`,
`frame [n]`. Public probe:
`tests/public/ch24_nes_apu_dma_sync/fixtures/drift_probe.txt`.
Challenge script lives inside the exercise dir; goldens under
`tests/public/ch24_nes_apu_dma_sync/goldens/`.

Runner CLI (mandatory shape): `--rom SCRIPT --frames N --headless
[--cycles M] [--trace FILE] [--hash-frame FILE] [--audio-out FILE]
[--input-file FILE]`. Audio is mono s16le, one sample per CPU cycle;
goldens are FNV-1a 64 over the raw bytes.
