# 91_challenge fixture provenance

## fixtures/gradient.bin

Synthetic S33N bundle (format documented in README.md and
fixtures/gradient.format.txt). Hand-assembled with a Python script; pure
arithmetic data, no hardware dumps, no commercial ROM content.

Generating script (run once; deterministic, byte-reproducible):

```python
import struct
def ramp(n): return min(15, n * 16 // 224)
config = (b"# ch33 public fixture: per-line INIDISP brightness gradient\n"
          b"# one direct channel, one fresh entry ($01 + byte) per line\n"
          b"watch=2100\nch0.enable=1\nch0.reg=2100\nch0.regs=1\n"
          b"ch0.indirect=0\nch0.table=0000:01c0\n")
blob = b"".join(bytes([0x01, ramp(n)]) for n in range(224))
rom = (b"S33N" + bytes([1,0,0,0]) + struct.pack("<I", len(config))
       + config + struct.pack("<I", len(blob)) + blob)
```
