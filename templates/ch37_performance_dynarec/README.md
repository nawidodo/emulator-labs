# ch37_performance_dynarec

Performance engineering for interpreters, on the toy **rx8** RISC core
(SPEC in `01_dispatch_bench/SPEC.md`): dispatch overhead, decode caching
with precise invalidation, basic blocks, a tiny host-independent IR, a
block-level code cache, and an executed-op-count optimization gate. All
grading uses executed-instruction / executed-IR-op counts — never wall time.

## Layout

| Dir | What |
|---|---|
| `01_dispatch_bench/` | The rx8 machine + switch-dispatch interpreter; fixed-program benchmark scored by executed-instruction count. |
| `02_decode_cache/` | Decode cache keyed by pc with byte-range store invalidation; SMC fixture proves sensitivity. |
| `03_basic_blocks_ir/` | Basic-block analyzer, guest→IR lowering, block-level code-cache engine with flush-on-store-to-code. |
| `04_opt_gate/` | Optimization passes over IR (identity folds, copy-prop, dec+branch fusion, liveness DCE); ≥20% executed-op reduction with identical dumps. |
| `90_debug/` | Seeded bug: decode cache never invalidated on stores → stale instructions execute under SMC. Write `bug-report.md`. |
| `91_challenge/` | Full pipeline (blocks → IR → optimized IR) bit-exact vs the switch interpreter on bench + SMC workloads. |
| `99_coding_test/` | Unseen rx8 extension opcodes (`mul`/`not`/`min`) wired through interpreter, translation, and optimized execution. |

## Fixture provenance

All programs under `tests/public|hidden/ch37_performance_dynarec/programs/`
are hand-assembled synthetic rx8 images (see `provenance.md` next to them).
No commercial ROMs. Golden hashes were generated by the reference solution,
run twice, byte-identical.
