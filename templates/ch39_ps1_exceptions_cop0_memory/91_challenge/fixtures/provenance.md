# bios_stub.bin — provenance

Hand-assembled synthetic BIOS stub for the ch39 boot-mini challenge.
464 bytes: 23 MIPS words placed at BIOS-image offsets 0x000-0x030 (reset /
mainline) and 0x180-0x1A4 (general exception handler), with the gap padded
to 0xFF so stray fetches trap as Reserved Instruction. Loaded at physical
0x1FC00000 and executed via KSEG1 at 0xBFC00000.

- Generated by a throwaway Python assembler (`gen_bios_stub.py`, not
  committed; the full disassembly is the authoritative listing in
  `bios_stub.asm.txt`).
- Exercises: SR setup via mtc0 (BEV=1), `bal` with a SYSCALL raised inside
  the branch delay slot (CAUSE.BD=1, EPC=branch address), the general
  exception handler at 0xBFC00180 saving CAUSE/EPC into the scratchpad,
  EPC adjustment (+8 to skip branch+slot), `jr $k1` with `rfe` in the delay
  slot, scratchpad round-trip load/store, completion marker 0x0000C0DE, and
  a final self-loop halt.
- Golden trace + state digest generated from this fixture live under
  `tests/public/ch39_ps1_exceptions_cop0_memory/traces/` (see the
  provenance.md there for generating commands).

No commercial code: every word above was chosen by hand for this course.
