# ch39 — PS1 Exceptions, COP0 and Memory Map

Exercises on the R3000A exception machinery: COP0 registers, the
exception-entry state transition, the PSX memory map, and a headless
"boot-mini" challenge that runs an exception prologue from a hand-assembled
synthetic BIOS stub. No `90_debug` this chapter; the unseen-spec coding test
(`99_coding_test`) covers interrupt delivery with BD/EPC semantics.

Reference: nocash PSX-SPX <https://problemkaputt.de/psx-spx.htm#cpuexceptions>.
See `LECTURE.md` for the full register tables, vectors, and worked example.

## Exercise map

| Dir               | Topic                                                                 | Tasks |
|-------------------|-----------------------------------------------------------------------|-------|
| `01_cop0_regs`    | SR/CAUSE/EPC/PRID; mfc0/mtc0 encodings; SR shadow push; RFE           | 3     |
| `02_exception_entry` | Exception entry as architectural state update: CAUSE/EPC (BD-aware), BEV vector select (`80000080h` vs `BFC00180h`), SR push | 1 |
| `03_memory_map`   | KUSEG/KSEG0/KSEG1/KSEG2, mirrors via `& 0x1FFFFFFF`, RAM window + 2 MB wrap, scratchpad (no KSEG1!), BIOS ROM, memory-control ports | 3 |
| `91_challenge`    | Boot-mini: synthetic BIOS stub (`fixtures/bios_stub.bin` + `.asm.txt` + provenance) executing syscall-in-delay-slot → handler → scratchpad → `jr;rfe`; headless runner with golden trace/state digest | 3 |
| `99_coding_test`  | Unseen sequence: timed software-interrupt line asserting mid-stream; deliverable() gating (IP & Im & IEc), delay-slot preemption, ack/retry vs skip policies | 2 |
