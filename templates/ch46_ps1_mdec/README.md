# ch46_ps1_mdec — MDEC video decoder

Exercises:

| Dir               | Topic                                                   |
|-------------------|---------------------------------------------------------|
| `01_rlz`          | RLZ bitstream decoder, dequantization, de-zigzag         |
| `02_idct`         | fixed-point separable IDCT with committed basis table    |
| `03_color_convert`| YCbCr->RGB15 (psx-spx constants), macroblock assembly    |
| `90_debug`        | seeded bugs: double zig-zag scan + wrap-instead-of-clamp |
| `91_challenge`    | DMA-fed frame decode -> hashed RGB15 output              |
| `99_coding_test`  | unseen compressed block -> exact pixel hash              |

Run:

```bash
LABS=ch46_ps1_mdec make skels && make build && ctest --test-dir build -R ch46
python3 tools/labs/generate.py --mode solution --force --targets ch46_ps1_mdec
cmake -S . -B build-solutions -DLABS_BUILD_SOLUTIONS=On && \
  cmake --build build-solutions -j && ctest --test-dir build-solutions -R ch46
```
