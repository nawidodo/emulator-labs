# ch48 Challenge — the virtual memory card round trip

Build a card image, write pattern sectors into it **through the raw SIO
protocol** on the dual-slot bus, export the 131072-byte `.mcr` bytes, remount
them into a completely fresh `MemCard`, and read the sectors back through
the protocol again. Every byte the card returns is pinned with an FNV-1a 64
digest (`kGoldenRoundtripFnv64` in `golden.hpp`).

Acceptance:

* both writes end with the good flag `0x5A`;
* a write aimed inside a directory-flagged bad block ends `0xFF` and changes
  nothing;
* after the remount the read-back stream (266 bytes: two sectors × [pre,
  3 mid flags, 128 payload, checksum, end flag]) hashes to the golden digest;
* the bad-block flag still trips on the remounted card.

The golden was generated by this chapter's reference solution — run twice,
byte-identical. See `tests/public/ch48_ps1_controllers_memcards/goldens/`
for provenance.
