# ch50 SPEC — the psx-mini reference machine

This chapter is self-contained: it does NOT import code from other chapters.
Everything accuracy-related is modelled by **psx-mini**, a compact, fully
deterministic stand-in for a PS1 living in this chapter's headers:

| Header                     | Contents                                              |
|----------------------------|-------------------------------------------------------|
| `shared/psx_mini.hpp`      | all seven subsystem models (reference behaviour)      |
| `shared/fnv.hpp`           | FNV-1a 64 hashing, identical to tools/labs            |
| `shared/goldens.hpp`       | golden pins generated by the reference solution       |
| `shared/fixture.hpp`       | the synthetic CPU fixture program                     |
| `01_suite_runner/checks.hpp` | built-in checks wrapping the models                 |
| `01_suite_runner/suite.hpp`  | suite-manifest grammar + report format              |
| `90_debug/regressions.hpp`   | ten seeded regression kernels                       |

psx-mini is honest about what it is NOT: it is not a MIPS core, not the real
GTE, not cycle-accurate anything. It exists so the *testing discipline* —
golden traces, hash corpora, state pins, regression suites — can be taught
end-to-end against a machine small enough to hold in your head.

## MiniCpu (`shared/psx_mini.hpp`)

8 GPRs (`r0..r7`, none hardwired), byte-addressed 4 KiB word RAM, one
32-bit instruction word: `op<31:24> rd<23:20> rs<19:16> rt<15:12> imm<11:0>`.

| op    | mnemonic | semantics                                   | cost |
|-------|----------|---------------------------------------------|------|
| 0x00  | nop      | –                                           | 1    |
| 0x01  | addi     | rd = rs + sext12(imm)                       | 1    |
| 0x02  | add      | rd = rs + rt                                | 1    |
| 0x03  | sub      | rd = rs - rt                                | 1    |
| 0x04  | xor      | rd = rs ^ rt                                | 1    |
| 0x05  | sll      | rd = rt << (imm & 31)                       | 1    |
| 0x06  | sra      | rd = rt >>a (imm & 31)                      | 1    |
| 0x07  | lw       | rd = mem[rs + uimm12]                       | 2    |
| 0x08  | sw       | mem[rs + uimm12] = rt   (rt is the data reg)| 2    |
| 0x09  | li       | rd = uimm12                                 | 1    |
| 0x0A  | beq      | taken → pc = at + 4 + sext12(imm)*4         | 1/2  |
| 0x0B  | bne      | as beq                                      | 1/2  |
| 0xFF  | halt     | stops the machine                           | 1    |

Trace lines use the course-wide format `pc=%08X op=%08X cyc=%llu`; the pc is
the fetch address of the instruction, cyc is cumulative INCLUDING that
instruction's cost. Branch targets are relative to the delay slot (at+4).
Illegal opcodes halt.

Fixture program: `kCpuProgram` (sums 5..1 into r1, stores to RAM byte
0x40, halts). Committed as
`tests/public/ch50_ps1_accuracy_trace_testing/fixtures/cpu_program.bin`
with listing `cpu_program.asm.txt`.

## MiniGpu

64 x 32 x 15-bit VRAM. Draws: `gpu_fill` (exclusive w/h rect),
`gpu_checker` ((x^y)&1 dither), `gpu_hgradient` (per-pixel additive ramp).
Whole-surface FNV-64 of the little-endian pixel buffer is THE VRAM hash
corpus analogue: any draw-path defect changes the digest.

## MiniSpu

One voice, 16-entry triangle wavetable (`kWaveTable`, values -105..105),
phase accumulator in 8.24 fixed point advanced by `pitch << 16` per sample,
linear envelope starting at 4096 decaying by 24 per sample (clamped at 0),
output `(wave[idx] * env) >> 12` clamped to s16. Sample hashes fold samples
straight into FNV-1a big-endian per 16-bit sample.

## DmaChan

`madr` (byte address), `bcr` (word count in the high half), `step`,
`enable`, `irq`. `dma_run_block` copies exactly `words` words, advances
madr by `step * words`, zeroes bcr, clears enable, latches irq. The
end-of-block register state IS the pin.

## MiniGte

3x3 row-major int16 matrix + int16 translation vector.
`mac_i = Σ_k m[i][k]*v[k] + tr[i]`; `ir_i = sat16(mac_i >> 12)`.
The >>12 lands ONCE on the accumulated dot product (see seed 08 for why).

## MiniTimer

Prescaled counter: every `div` sysclks the counter increments once; on the
tick where `cnt == target` EXACTLY, cnt reloads to 0 and `reached++`.

## MiniCdrom

MSF addressing: `f = lba % 75`, `s = (lba/75) % 60`, `m = lba/4500`, each
BCD-coded (`bcd_enc`/`bcd_dec`). Sector payloads are synthetic but stable:
an xorshift stream seeded by the LBA with the BCD MSF header overlaid in
bytes 0..2 and mode marker 0x10 in byte 3. A read walk folds each sector's
FNV into `CdromState::data_hash`.

## Suite manifest grammar (`suite.hpp`)

```
# comment
case <name> builtin.<check>
case <name> <executable-path> [args...]
```

Blank lines and `#` comments are skipped; malformed lines become FAILing
cases (never crashes). The runner prints `PASS <name>` / `FAIL <name>:
<reason>` per case then `== <passed>/<total> checks passed`, exits 0 iff
everything passed.
