# Provenance — tests/hidden/ch09_space_invaders_machine

Course-original fixtures for the Arcade-8080-B coding test (fictional
board, spec in templates/ch09_space_invaders_machine/99_coding_test/
CODING_TEST.md). Assembled with the chapter author's two-pass assembler;
listings in the adjacent `.asm.txt` files. No third-party ROM content.

## roms/sib_ports.bin

Exercises both B-board shifters through OUT 2 amount split (bits 0-2 -> #1,
bits 3-5 -> #2), data writes on OUT 6 / OUT 7, results read back from IN 6 /
IN 7 into RAM 4000/4001 (expected 0x04 / 0xC2), plus sound events and a
watchdog kick.

## roms/sib_irq.bin

Interrupt cadence: counting handlers at vectors 0x18 / 0x30 bump words at
0x4000 / 0x4002. Seven frame periods budgeted; program halts at ~183k
cycles after crossing five boundaries -> counters 3 / 2.

## roms/sib_video.bin

Gradient-fills all 7 KiB of VRAM (byte k = k & 0xFF) with orientation
marks, then halts (~279633 cycles ≈ 7.8 frames of 36000).

## Golden outputs

Generated by the reference-solution runner `ch09_99_si_b_runner`, each run
TWICE byte-identical:

```bash
ch09_99_si_b_runner --rom roms/sib_ports.bin
# AF=2202 BC=0000 DE=0000 HL=0000 SP=4200 PC=002D cyc=196

ch09_99_si_b_runner --rom roms/sib_irq.bin --frames 7
# AF=0046 BC=0000 DE=0000 HL=0000 SP=4200 PC=0060 cyc=182961

ch09_99_si_b_runner --rom roms/sib_video.bin --frames 9 --hash-frame <f>
# AF=0156 BC=0000 DE=0000 HL=6000 SP=4300 PC=001E cyc=279633
# frame FNV64 A00CD2A9E86A9304
```
