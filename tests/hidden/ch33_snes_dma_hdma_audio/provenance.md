# ch33 hidden fixture provenance

## roms/hidden_ramp.bin

Synthetic S33N bundle (format documented in
templates/ch33_snes_dma_hdma_audio/README.md). Hand-assembled with a Python
script; pure arithmetic data, no hardware dumps, no commercial ROM content.

Contents:

- watch=$2100
- channel 0: DIRECT table at blob $0000 (15 bytes), mixed entry shapes
  (every non-repeat line consumes its own data byte):

  ```text
  $02,$01,$01   lines 0-1   value 01, fresh fetch each line
  $02,$02,$02   lines 2-3   value 02, fresh fetch each line
  $84,$07       lines 4-7   REPEAT: fetched once on line 4,
                            lines 5-7 hold silently (no writes)
  $02,$05,$05   lines 8-9   value 05
  $02,$06,$06   lines 10-11 value 06
  $00           terminate at line 12; lines 12-223 hold the last value
  ```

- channel 1: INDIRECT table at blob $0010 (8 bytes): header `$03` then one
  little-endian pointer PER LINE ($0020, $0022, $0024), then `$00`
  termination. Indirect data at blob $0020: AA BB CC DD EE FF -- two
  registers ($2101, $2102) written per line for lines 0-2.

Expected effect buffer (watch=$2100): `01 01 | 02 02 | 07 07 07 07 | 05 05 |
06 x212` — the repeat entry holds $2100 at 07 across lines 4-7 without
rewrites, and the terminated channel leaves the last value (06) standing
for the rest of the frame. Channel 1 is invisible in the hash (watched
register differs) but exercised by --trace.

Generating script (deterministic):

```python
import struct
config = (b"# ch33 hidden fixture: mixed entry shapes, two channels\n"
          b"watch=2100\nch0.enable=1\nch0.reg=2100\nch0.regs=1\n"
          b"ch0.indirect=0\nch0.table=0000:000f\n"
          b"ch1.enable=1\nch1.reg=2101\nch1.regs=2\n"
          b"ch1.indirect=1\nch1.bank=00\nch1.table=0010:0008\n")
hb = bytearray(0x26)
for i, v in enumerate([0x02,0x01,0x01, 0x02,0x02,0x02, 0x84,0x07,
                       0x02,0x05,0x05, 0x02,0x06,0x06, 0x00]): hb[i] = v
hb[0x10:0x18] = bytes([0x03, 0x20,0x00, 0x22,0x00, 0x24,0x00, 0x00])
hb[0x20:0x26] = bytes([0xAA,0xBB, 0xCC,0xDD, 0xEE,0xFF])
rom = (b"S33N" + bytes([1,0,0,0]) + struct.pack("<I", len(config))
       + config + struct.pack("<I", len(hb)) + bytes(hb))
```
