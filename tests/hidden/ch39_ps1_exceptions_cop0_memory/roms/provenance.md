# bios_stub.bin — provenance

Hand-assembled synthetic BIOS stub for the ch39 boot-mini hidden grader.
464 bytes (23 MIPS words at offsets 0x000-0x030 and 0x180-0x1A4, gap padded
with 0xFF), loaded at physical 0x1FC00000 and executed via KSEG1 at
0xBFC00000. Identical copy of
`templates/ch39_ps1_exceptions_cop0_memory/91_challenge/fixtures/`.

- Generated by a throwaway Python assembler; the authoritative listing is
  `bios_stub.asm.txt`.
- Exercises: SR setup via `mtc0` (BEV=1), `bal` whose DELAY SLOT contains a
  `syscall` (CAUSE.BD=1, EPC = branch address 0xBFC0000C), general exception
  handler at 0xBFC00180 saving CAUSE/EPC into the scratchpad through KSEG0,
  EPC += 8 to skip branch + slot, `jr $k1` with `rfe` in the jump's delay
  slot, scratchpad round-trip load/store, completion marker 0x0000C0DE,
  final self-loop halt.

No commercial code: every word was chosen by hand for this course.
