# ch48 hidden manifest provenance

All hashes were generated with the reference solution
(`generate.py --mode solution`), run TWICE per case; both runs were
byte-identical before committing.

## Fixtures (`roms/`)

* `card_unseen.mcr` — synthetic 131072-byte `.mcr`, deterministic
  construction: header `"MC"`, entry block 3 `UNSEEN.ROM` (in use, size 1,
  good), entry block 5 `BROKEN.SAV` (in use, size 2, attribute bit 7 =
  BAD block), block 3 data at sectors 192..255 filled with
  `(0x5C + i*3) & 0xFF`. No commercial or dumped material.
* `script_a.script` / `script_b.script` — unseen SIO transaction logs in the
  runner grammar (`SLOT/PAD/XFER/RUN`); script B embeds a protocol WRITE
  whose XOR checksum (`0x80`) was computed over its exact payload, plus a
  write aimed inside the bad block and reads of untouched sectors.
