# provenance.md — golden traces for ch02_emulator_core

All goldens were generated by the REFERENCE implementation (the complete
LAB-8 core in `templates/ch02_emulator_core/04_assembler_fixture/`), run
TWICE per program with byte-identical results (docs/AUTHORING.md golden data
policy).

Generating command (from a build of the exercise's `ch02_04_runner`):

```bash
for p in countdown sum_mem fib; do
  ./ch02_04_runner --rom tests/public/ch02_emulator_core/roms/$p.bin \
                   --cycles 400 \
                   --trace tests/public/ch02_emulator_core/traces/$p.log
done
# note: sum_mem.bin -> traces/summem.log (name without underscore)
```

Reproducibility check performed at authoring time: each trace was generated
in two independent runs and compared byte-for-byte (`cmp`) — identical.

| File | Program | Result |
|---|---|---|
| `countdown.log` | `programs/countdown.asm.txt` | halts after 73 cycles, 23 instructions |
| `summem.log` | `programs/sum_mem.asm.txt` | halts after 36 cycles, mem[0x80]=6 |
| `fib.log` | `programs/fib.asm.txt` | budget-limited at 400 cycles, never halts |

The `.bin` images under `roms/` are exact copies of the committed binaries in
`templates/ch02_emulator_core/04_assembler_fixture/programs/`, whose
`.asm.txt` listings are the human-readable source of truth.

Compare any implementation's trace against these goldens:

```bash
./ch02_04_runner --rom tests/public/ch02_emulator_core/roms/fib.bin \
                 --cycles 400 --trace /tmp/actual.log
python3 tools/labs/compare_trace.py \
    tests/public/ch02_emulator_core/traces/fib.log /tmp/actual.log
```
