# Provenance — ch06_chip8_accuracy_debugger golden data

Every golden in this directory was produced by the chapter's REFERENCE
solution (`tools/labs/generate.py --mode solution --targets
ch06_chip8_accuracy_debugger`), never by hand. Each generating command was
run TWICE; both outputs compared byte-identical before committing.

## Fixtures

Hand-assembled synthetic programs (no commercial ROMs). Committed as
`fixtures/<name>.bin` with a `.asm.txt` disassembly; the same byte arrays
are embedded in the chapter's test sources, so tests never depend on these
files at runtime.

## Golden traces (`traces/*.log`)

Generated with the reference runner:

```bash
R=<solution build>/ch06_01_trace_runner
FX=tests/public/ch06_chip8_accuracy_debugger/fixtures
T=tests/public/ch06_chip8_accuracy_debugger/traces

for f in q1_shift q2_loadstore q3_jump q4_draw_wrap q5_vfreset; do
  $R --rom $FX/$f.bin --quirks MODERN --cycles 8 --trace $T/${f}_modern.full.log --trace-full
done
$R --rom $FX/divergence.bin    --quirks COSMAC_VIP --cycles 8 --trace $T/divergence_vip.full.log    --trace-full
$R --rom $FX/divergence.bin    --quirks MODERN     --cycles 8 --trace $T/divergence_modern.full.log --trace-full
$R --rom $FX/save_reload.bin   --quirks COSMAC_VIP --cycles 6 --trace $T/save_reload_vip.full.log   --trace-full
```

`mystery_chip48.full.log` is the reference trace for the hidden coding-test
ROM (`tests/hidden/ch06_chip8_accuracy_debugger/roms/mystery.bin`) under its
correct profile:

```bash
$R --rom tests/hidden/ch06_chip8_accuracy_debugger/roms/mystery.bin \
   --quirks CHIP48 --cycles 8 --trace traces/mystery_chip48.full.log --trace-full
```

## Hidden-manifest hashes

`fnv64` values in `tests/hidden/ch06_chip8_accuracy_debugger/manifest.json`
are FNV-1a 64 of the exact bytes the graded commands write (same algorithm
as `tools/labs/hash_frame.py`), computed from the twice-run outputs above:
probe full trace `8736B29264D791A5`, mystery CHIP48 full trace
`88F9CB62E9C4C408`.
