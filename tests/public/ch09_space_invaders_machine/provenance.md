# Provenance — tests/public/ch09_space_invaders_machine

Course-original, hand-assembled fixtures (assembled with the chapter
author's two-pass assembler; listings are the adjacent `.asm.txt` files).
No third-party ROM content.

## roms/ch09_cadence.bin

Interrupt-cadence fixture: mainline delay loop (~163k T-states), counting
RST 08 / RST 10 handlers bumping words at 0x2000 / 0x2002. Vector thunks
at 0x0000/0x0008/0x0010, handlers after the mainline.

## roms/ch09_pattern.bin

Video test pattern: gradient-fills all 7 KiB of VRAM (byte k = k & 0xFF)
plus explicit orientation marks (columns 0/17/64 top bytes = 0xFF, single
pixel at col 223 / row 255). Halts at ~279646 T-states (~8.7 frames).

## roms/ch09_si_diag.bin + input/ch09_si_diag.inputs

The 91_challenge diagnostic: shift-register round trip (OUT 2 amount 3,
OUT 4 low/high fill, IN 3 must read 0xBB; verdict byte stored at 0x2004),
IN 1 latch sample (fire bit from the input script), sound/watchdog events,
counting RST handlers at 0x2010/0x2012 and RST-10-painted VRAM.

## traces/ch09_cadence.log

Generated by the reference-solution runner at test-scale timing (six frame
periods of 500 cycles so several boundaries fit in a small trace), run
TWICE — byte-identical both times:

```bash
ch09_04_cadence_runner --rom roms/ch09_cadence.bin --cpf 500 --frames 6 --trace <file>
# FNV64 9914B5E36957A739   (463 lines)
```

## Frame hashes (FNV-1a 64 over raw RGBA8888 dumps)

All generated by reference-solution runners, run twice byte-identical:

```bash
ch09_05_si_runner --rom roms/ch09_pattern.bin --frames 9 --hash-frame <f>
# final state: AF=8056 BC=0000 DE=0000 HL=4000 SP=2300 PC=0021 cyc=279646
# FNV64 3709E7FC1B51FC35
```
