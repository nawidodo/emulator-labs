# ch13 public fixtures and goldens provenance

## Fixture

`fixtures/timer_probe.bin` is assembled from `fixtures/timer_probe.asm.txt`
with the course mini-assembler:

    python3 -c "import sys; sys.path.insert(0,'/tmp/labs-gb1'); \
from sm83asm import assemble; \
code,labels=assemble(open('timer_probe.asm.txt').read()); \
open('timer_probe.bin','wb').write(code)"

Verified assembler behavior for this fixture (2026-08-25, sm83asm.py with
the `($ffXX),a` LDH-store fix): the `org` directive PADS with zero bytes,
labels resolve to offsets from 0 (`isr`=0x050, `main`=0x100,
`halt_loop`=0x111), output is 276 bytes. The binary is loaded by the
runner at base $0000, so the ISR lands at $0050 and main at $0100 (SM83
reset vector). Labels are only used for the relative `jr`; all absolute
targets are literal `$hex`. Never hand-edit the `.bin`.

Program behavior: TMA=$E0 / TAC=$04 (enabled, DIV bit 9 -> one tick per
1024 T-cycles), IE=$04 unmasks the timer line, EI + HALT loop; the ISR at
$0050 increments the HRAM counter at $FF80. One interrupt every 32768
T-cycles.
