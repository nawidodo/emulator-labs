# provenance — ch16_gameboy_cartridges_mbc (public fixtures & goldens)

## Generation

All carts are synthesized; no commercial ROM data exists in this
directory. From `tests/public/ch16_gameboy_cartridges_mbc/`:

```bash
python3 tools/make_roms.py        # deterministic, no RNG, no wall clock
```

Outputs (into `roms/`):

| file | banks | header type | RAM code | title |
|------|-------|-------------|----------|-------|
| rom_only.gb | 2 (32 KiB) | $00 ROM_ONLY | $00 | CH16ROMONLY |
| mbc1_512k.gb | 32 (512 KiB) | $03 MBC1+RAM+BATTERY | $02 | CH16MBC1512 |
| mbc1_2m.gb | 128 (2 MiB) | $03 MBC1+RAM+BATTERY | $02 | CH16MBC12M |
| mbc3_timer.gb | 64 (1 MiB) | $0F MBC3+TIMER+BATTERY | $03 | CH16MBC3RTC |
| mbc5_1m.gb | 64 (1 MiB) | $19 MBC5+RAM | $02 | CH16MBC51M |

Pattern rule: byte = bank index & 0xFF everywhere except the bank-0
header hole ($000-$14F, which carries the real header with a valid
checksum). The generator prints a header hexdump listing for each cart.
The 9-bit MBC5 behavior is deliberately unit-tested via seams instead of
committing an 8 MiB image.

## Coverage table

| fixture | exercises it feeds |
|---------|--------------------|
| rom_only.gb | runner smoke / factory dispatch |
| mbc1_512k.gb | challenge c1 (banking, mode switch, RAM gate) |
| mbc1_2m.gb | available for manual mode-1 low-half exploration on >32-bank carts |
| mbc3_timer.gb | challenge c2 (injected-tick RTC + latch) |
| mbc5_1m.gb | challenge c3 (nine-bit selects wrapping mod 64) |

## Golden hashes

Generated by running the reference-solution runner TWICE per case with
identical args (`cmp` byte-identical), from repo root:

```bash
RUNNER=<solution tree>/05_cart_runner/ch16_05_cart_runner
PUB=tests/public/ch16_gameboy_cartridges_mbc
$RUNNER --rom $PUB/roms/mbc1_512k.gb --headless \
    --input-file $PUB/ops/c1_mbc1_banks.ops --trace /tmp/c1.log
# ... likewise c2 (mbc3_timer.gb) and c3 (mbc5_1m.gb)
python3 tools/labs/hash_frame.py /tmp/c1.log --fnv-only
```

| trace | fnv64 |
|-------|-------|
| ops/c1_mbc1_banks.ops over mbc1_512k.gb | `256EC39539CE01A8` |
| ops/c2_mbc3_rtc.ops over mbc3_timer.gb | `0D88972BE8E11F32` |
| ops/c3_mbc5_high.ops over mbc5_1m.gb | `0FB5C9B062066D20` |

`templates/ch16_gameboy_cartridges_mbc/91_challenge/CHALLENGE.md`.
