# Provenance — ch19 public fixtures and goldens

All fixtures are course-original, generated by the reference ch19 core
(`templates/ch19_nes_cpu_accuracy`, solution mode). Every golden below was
produced TWICE from the reference binaries and verified byte-identical.

## programs/challenge_prog.bin (+ .asm.txt)

Hand-assembled course-original program (assembler script equivalent to the
committed listing; layout: main flow at $0600, ADC/RTS subroutine copy at
$0670, INC-counter IRQ handler at $0690). Self-contained: installs its own
$FFFE/$FFFF vectors (NMI parked at the same handler) before CLI. No
commercial ROM content.

## traces/challenge_golden.log

```
build via templates/ch19_nes_cpu_accuracy/91_challenge/runner_main.cpp
ch19_91_challenge_runner --rom tests/public/ch19_nes_cpu_accuracy/programs/challenge_prog.bin \
    --cycles 100 --trace-log challenge_golden.log
```
51 nestest-style lines (format contract in 03_trace_log/SPEC.md).
FNV-1a 64 of the file: EA9553DE3CA91C80.

## traces/good50k.log / bad50k.log

Reference core running `ADC #$01 ; INX ; JMP $0600` at $0600 on flat RAM,
50000 instructions logged in canonical key=value trace format.
`bad50k.log` is byte-identical to `good50k.log` except line 49867, whose
cycle count was decremented by one (the classic "dummy read dropped"
symptom). Generated once by the reference core, then derived by text
substitution — no second source exists by construction.
