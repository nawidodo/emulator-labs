# Provenance — ch25_arm7tdmi_arm_isa public fixtures & goldens

All fixtures are synthetic programs hand-assembled with a deterministic
generator script; no commercial or downloaded ROM data is used.

## roms/

- `branch_demo.bin` (+ `.asm.txt`): MOV/ADD/BL/BX-return/SUBS/self-loop.
  Exercises data processing, BL link (LR = pc+4), BX, flag setting.
- `blockcopy.bin` (+ `.asm.txt`): two LDMIA/STMIA block copies
  src(0x400) -> dst(0x800) followed by an add-shift checksum loop over the
  eight destination words (`w[i] = (i+1) * 0x01010101`, ASR #2 accumulated).
  Expected checksum `r3 = 0x09090906`. Used by the 91_challenge acceptance
  criteria.
- `roms/status_swap.bin` (+ `.asm.txt`): SWP/SWPB/MRS/MSR sequence for the
  99_coding_test family, with one data word `0xDEADBEEF` at 0x500.

## traces/ and goldens/

- `traces/branch_demo.log`: canonical trace of the chapter runner,
  generated by the reference solution:
  `ch25_runner --rom roms/branch_demo.bin --headless --cycles 12 --trace ...`
- `traces/status_swap.log`: same procedure via `ch25_coding_runner`
  (`--cycles 20`).
- `goldens/blockcopy.dump`: final register dump via `ch25_challenge_runner`
  (`--cycles 62`).

Every artifact was generated TWICE by the reference solution runners and
byte-compared before committing; all pairs were identical. The hidden
manifest hashes (`tests/hidden/ch25_arm7tdmi_arm_isa/manifest.json`) were
computed from those same reference outputs (FNV-1a 64).

## Hidden fixtures

`tests/hidden/ch25_arm7tdmi_arm_isa/roms/hidden_branches.bin`
(+ `.asm.txt`) is a countdown + BL/BX call program that never appears in
public material; its golden dump hash lives only in the hidden manifest.
