# Provenance — ch28_gba_ppu public fixtures & goldens

All fixtures are synthetic; no commercial or downloaded ROM data is used.

## fixtures/mode4_blend.pps (+ .txt listing)

Hand-written `.pps` MMIO-write script (format: repeating little-endian
`{u32 addr, u16 value}` records, `0xFFFFFFFF` terminator). Scene: mode 4
paletted diagonal stripes from a fixed arithmetic ramp, one 8x8 OBJ sprite
(tile 1, priority 1) at (40,40), palette ramp `i -> (7i, 5i, 3i) mod 32`.

## frames/

- `sample_snap_reference.rgba`: rendered from `snapshots/sample.snap` by the
  reference solution (`ch28_snapshot_tool`). Command:
  `ch28_snapshot_tool snapshots/sample.snap sample_snap_reference.rgba`
- `hidden_snap_reference.rgba`: reference render of the hidden snapshot
  (kept for collision forensics only).
- Challenge golden digest: embedded in
  `templates/ch28_gba_ppu/91_challenge/main.cpp` (`kGolden = 7D5D14F3D2397BE5`),
  produced by running the solution-tree challenge test twice and comparing.

Every artifact was generated **twice** by the reference solution and
byte-compared before committing; all pairs were identical.

## snapshots/sample.snap

Generated by a one-off deterministic generator (not committed) that fills
IO/PAL/VRAM/OAM with fixed arithmetic patterns exercising mode 1 (text BG0 +
affine BG2), two sprites (one semi-transparent) and alpha blending. The
generator contains no randomness and no time dependence.
