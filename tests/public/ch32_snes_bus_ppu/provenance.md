# Provenance — ch32_snes_bus_ppu goldens and fixtures

All fixtures are synthetic (no commercial ROMs). Goldens were produced by
the reference SOLUTION build under /tmp/labs-SNES-ch32, run TWICE per
artifact; outputs were byte-identical (`cmp`) before hashing.

## Scene bundles (.sns)

Generated by `templates/ch32_snes_bus_ppu/91_challenge/fixtures/make_scenes.py`
(deterministic: fixed loops, no RNG, no time):

```
cd templates/ch32_snes_bus_ppu/91_challenge/fixtures && python3 make_scenes.py
```

* `roms/baseline.sns`  — Mode 1 scene: two 4bpp layers + 2bpp layer,
  window [48,143] with layer mask, add-half color math.
* `roms/mode7_zoom.sns` — Mode 7 scene: ~11-degree rotation + 1.25x zoom,
  backdrop fill outside the map.

## Golden frame digests (FNV-1a-64 of the raw 256x224x4 RGBA dump)

Generating commands (binary = the chapter's solution runner):

```
ch32_91_scene_runner --rom <baseline.sns>  --headless --frames 1 --hash-frame f.rgba   -> 8BD7BF88470974A5
ch32_91_scene_runner --rom <mode7_zoom.sns> --headless --frames 1 --hash-frame f.rgba  -> 2564D946AB36EC88
ch32_03_render_runner --headless --frames 1 --hash-frame f.rgba                        -> 093F20DF5AF48525
```

Digest tool: `python3 tools/labs/hash_frame.py f.rgba`.
