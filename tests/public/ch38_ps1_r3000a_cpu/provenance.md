# Provenance — ch38 public fixtures & goldens

## roms/cpu_smoke.bin

Hand-assembled from `cpu_smoke.asm.txt` (this directory) with a throwaway
MIPS I assembler script; no external toolchain involved. 30 instructions at
0x80010000, halting via `syscall`. Exercises: ALU loop with taken-branch
delay slot, word/byte stores through KSEG0 mirrors, lwl/lwr unaligned load
pair, mult/div into HI/LO with mfhi/mflo, jal/jr call returning through a
delay slot.

## traces/cpu_smoke.trace + hashes.txt

Generated by the reference solution runner (solution build of
`templates/ch38_ps1_r3000a_cpu/91_challenge`):

```bash
ch38_91_challenge_runner --rom tests/public/ch38_ps1_r3000a_cpu/roms/cpu_smoke.bin \
    --cycles 2000 --headless \
    --trace tests/public/ch38_ps1_r3000a_cpu/traces/cpu_smoke.trace \
    --hash-frame /tmp/h.txt
```

Executed twice; trace bytes and the `fnv64=` payload were byte-identical on
both runs (halted=1 cycles=105 pc=80010068).
