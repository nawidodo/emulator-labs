this chapter), run TWICE with byte-identical results.

## Generating commands (from the solution tree)

```sh
# 91_challenge boot-mini golden trace + final-state digest
./ch39_91_challenge_runner \
    --rom <repo>/tests/hidden/ch39_ps1_exceptions_cop0_memory/roms/bios_stub.bin \
    --cycles 48 --headless \
    --trace boot_mini_trace.log --hash-frame boot_mini_state.txt
# -> boot_mini_state.txt: fnv64=7800B8D044458070  (scratchpad+GPR+COP0 digest)
# -> boot_mini_trace.log: fnv64=FAF35BD4B54BEE86  (FNV-1a-64 over the file)

# 99_coding_test unseen-sequence golden trace + final-state digest
./ch39_99_coding_test_runner --cycles 96 --headless \
    --trace coding_test_trace.log --hash-frame coding_test_state.txt
# -> coding_test_state.txt: fnv64=057C70A684EE420F
# -> coding_test_trace.log: fnv64=AD6A962A1A4E7280
```

Hash algorithm: FNV-1a 64-bit, offset basis 0xCBF29CE484222325, prime
0x100000001B3, printed as 16 uppercase hex digits (identical to
tools/labs/grade.py).

The `*_state.txt` payload covers scratchpad (1024 bytes) + all 32 GPRs +
final PC + SR/CAUSE/EPC + cycle count, little-endian.

Note on hashing: the runner writes `fnv64=<digest>\n` where <digest> is the
state digest. The hidden manifest's `expect_file_hash` is FNV-1a-64 over the
WHOLE produced file (grade.py semantics), so for coding_test.state it is
`AB0F937ADC2F81E9` while the printed digest inside the file is
`057C70A684EE420F`.
