# ch45_ps1_cdrom — fixture provenance

Disc images are synthetic MODE2/2352 binaries generated by a documented
deterministic Python routine (sync pattern + BCD MSF header per sector,
form1 subheader, user data filled with (pattern*7*sector + index) & 0xFF).
No copyrighted material. CUE sheets are minimal single-track MODE2/2352.

- `disc/pub.bin|pub.cue` — 64 sectors, byte pattern base 1.
- `scripts/pub.script` — scripted controller session; golden transcript
  `scripts/pub_expected.log` produced by the reference solution:

      build/skels/ch45_ps1_cdrom/91_challenge/ch45_cd_cli \
        --cue tests/public/ch45_ps1_cdrom/disc/pub.cue \
        --bin tests/public/ch45_ps1_cdrom/disc/pub.bin \
        --script tests/public/ch45_ps1_cdrom/scripts/pub.script

Run twice; transcripts byte-identical.
