# ch47 golden data provenance

All goldens were generated by this chapter's reference solution
(`generate.py --mode solution`), run twice per artifact; both runs were
byte-identical before committing.

## tests/public/ch47_ps1_spu/goldens/jingle.pcm

4000 stereo frames (16000 bytes, interleaved s16le) produced by:

```bash
build/skels/ch47_ps1_spu/05_mix/ch47_05_spu_runner \
  --rom tests/public/ch47_ps1_spu/adpcm/jingle.bin \
  --input-file tests/public/ch47_ps1_spu/scripts/jingle.script \
  --hash-frame goldens/jingle.pcm --headless
```

FNV-1a 64: `65781DCA7BF9338D`

The same digest is pinned in `templates/ch47_ps1_spu/91_challenge/golden.hpp`
(`kGoldenJinglePcmFnv64`) and is reproduced by the in-tree challenge test.

## Fixtures

* `adpcm/jingle.bin` + `adpcm/jingle.asm.txt`: synthetic hand-assembled
  PSX ADPCM (4 blocks, loop start/end markers). No commercial or dumped
  material; nibble patterns are deterministic arithmetic sequences
  documented in the listing.
* Hidden fixtures under `tests/hidden/ch47_ps1_spu/roms/` follow the same
  construction (`unseen_stream.asm.txt` documents every byte).
