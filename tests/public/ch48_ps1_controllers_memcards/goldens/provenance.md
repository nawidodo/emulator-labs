## Fixtures

* `cards/sample.mcr`: synthetic 131072-byte `.mcr`. Construction
  (deterministic, no commercial or dumped material):
  ```python
  img = bytearray(b"\xFF" * 131072); img[0:2] = b"MC"
  # entry block 1 @ sector 1: A0 'size=2' "SAMPLE.DAT", attr=0x00
  # entry block 2 @ sector 2: A0 'size=1' "BADONE.DAT", attr=0x80 (BAD)
  # block 1 data (sectors 64..127): byte = (0x20 + i*3) & 0xFF
  # block 2 data (sectors 128..191): byte = (0xEE + i*3) & 0xFF (flagged bad)
  ```
* `scripts/*.script`: plain-text SIO transaction logs in the grammar of
  `templates/ch48_ps1_controllers_memcards/03_card_image/SPEC.md`.
* Hidden fixtures under `tests/hidden/ch48_ps1_controllers_memcards/roms/`
  follow the same construction (`card_unseen.mcr`: entry block 3
  "UNSEEN.ROM" good, entry block 5 "BROKEN.SAV" bad-flagged, block 3 data =
  `(0x5C + i*3) & 0xFF`; hidden scripts exercise both slots, GETID, erase
  and writes into a bad block).
