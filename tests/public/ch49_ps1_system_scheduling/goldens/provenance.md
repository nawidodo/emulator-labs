# ch49 public goldens — provenance

All goldens generated by the reference solution (`--mode solution` tree),
run TWICE, byte-identical both times. Synthetic fixtures only; the boot
program is hand-assembled from `roms/boot_handshake.asm.txt` (mini-ISA
encoding per `templates/ch49_ps1_system_scheduling/02_mini_devices/
core.hpp`).

Generating command:

```bash
ch49_03_boot_runner_runner \
    --rom tests/public/ch49_ps1_system_scheduling/roms/boot_handshake.bin \
    --cycles 40000 \
    --hash-frame tests/public/ch49_ps1_system_scheduling/goldens/boot_handshake.eventlog \
    --trace tests/public/ch49_ps1_system_scheduling/traces/boot_handshake.trace \
    --headless
# stdout both runs: events=37 cyc=39936 halted=1 fnv64=760C13EA4039747C
```

- `goldens/boot_handshake.eventlog` — 37 event lines (boot, milestones,
  GPU busy/idle, IRQ latches in dispatch order, cd_done, halt); FNV-1a 64
  over the raw bytes = `760C13EA4039747C`.
- `traces/boot_handshake.trace` — canonical instruction trace
  (`pc=<hex8> op=<hex8> cyc=<n>`), one line per executed instruction.
