# ch50 golden data provenance

All goldens were generated by this chapter's reference solution
(`generate.py --mode solution`), run twice per artifact; both runs were
byte-identical before committing.

## Fixtures

* `fixtures/cpu_program.bin` + `fixtures/cpu_program.asm.txt`: synthetic
  hand-assembled psx-mini program (7 words: sum 5..1 into r1, store at
  RAM byte 0x40, halt). No commercial or dumped material. The identical
  word array lives in `templates/ch50_ps1_accuracy_trace_testing/shared/
  fixture.hpp` so suites stay self-contained in isolated build trees.
